# AI智能应用中心

一个基于Vue3的AI聊天应用前端项目，包含两个专门的AI助手应用。

## 🚀 功能特性

### 主要功能
- **主页导航**: 美观的应用选择界面
- **AI恋爱大师**: 专业的恋爱咨询助手
- **AI超级智能体**: 通用AI助手Manus
- **实时聊天**: 基于SSE (Server-Sent Events) 的实时消息流
- **响应式设计**: 适配桌面和移动设备

### 技术特性
- 🎨 现代化UI设计，渐变背景和毛玻璃效果
- 📱 响应式布局，完美适配各种屏幕
- ⚡ 实时消息流，流畅的用户体验
- 🔄 智能错误处理和连接状态显示
- 💬 类似微信的聊天界面设计

## 🛠 技术栈

- **Vue 3** - 渐进式JavaScript框架
- **Vue Router 4** - 官方路由管理器
- **Axios** - HTTP客户端库
- **Vite** - 快速构建工具
- **SSE** - Server-Sent Events实时通信

## 📦 项目结构

```
src/

├── router/            # 路由配置
```

## 🔗 后端接口

### 基础信息
- **接口地址**: `http://localhost:8123/api`
- **通信方式**: Server-Sent Events (SSE)

### API接口

#### 1. AI恋爱大师聊天接口
- **路径**: `/ai/love_app_chat/sse_emitter`
- **方法**: GET
- **参数**:
  - `message`: 用户消息内容
  - `chatId`: 聊天室ID (自动生成)

#### 2. AI超级智能体聊天接口
- **路径**: `/ai/manus/chat`
- **方法**: GET
- **参数**:
  - `message`: 用户消息内容

## 💡 使用说明

### 主页导航
1. 打开应用后会看到主页，显示两个AI应用选项
2. 点击对应的卡片进入不同的聊天应用

### AI恋爱大师
1. 专门用于恋爱咨询和情感建议
2. 进入页面后会自动分配聊天室ID
3. 输入恋爱相关问题，AI会实时回复专业建议

### AI超级智能体
1. 通用AI助手，可处理各种类型问题
2. 支持学习、工作、生活等多方面咨询
3. 提供更全面的知识支持

### 聊天操作
- **发送消息**: 输入文本后点击发送按钮或按Enter键
- **实时响应**: AI回复会实时流式显示
- **返回主页**: 点击左上角返回按钮

## 🎨 设计特色

### 视觉设计
- **渐变背景**: 使用CSS渐变创造现代视觉效果
- **毛玻璃效果**: backdrop-filter实现的模糊透明效果
- **动画交互**: 丰富的hover和点击动画
- **响应式布局**: 完美适配各种设备

### 用户体验
- **即时反馈**: 按钮状态、加载动画、错误提示
- **流畅动画**: 页面切换和元素交互动画
- **清晰层次**: 良好的信息架构和视觉层次

## 🔧 配置说明

### API配置
如需修改后端接口地址，请编辑 `src/services/api.js` 文件中的 `BASE_URL` 常量。

### 路由配置
路由配置位于 `src/router/index.js`，可根据需要添加或修改路由。

- 优化的移动端聊天体验

## 🐛 常见问题

### SSE连接问题
如果遇到连接问题，请检查：
1. 后端服务是否正常运行
2. 网络连接是否稳定
3. 浏览器是否支持SSE

### 开发环境问题
如果开发服务器启动失败：
1. 检查Node.js版本是否>=14
2. 删除node_modules重新安装依赖
3. 检查端口是否被占用
